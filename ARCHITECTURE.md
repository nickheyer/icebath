# Architecture of Icebath

> Paths are relative to `pkg/`

## Core

- **`acp`** — Runs icebath as an Agent Client Protocol agent server: sessions, auth methods, permissions, edit approvals, gateway loop.
- **`acpclient`** — OpenAI-client-shaped facade driving external ACP agent CLIs (such as Copilot) over stdio as model providers.
- **`activesessions`** — Registry of live session leases with owner liveness checks, concurrency caps and refusal messages.
- **`agent`** — The core tool-calling agent (`AIAgent`): initialization, turn loop, context compression, delegation, recovery, trajectories.
- **`agentimport`** — `import-agent` and `claw` commands that preview, confirm and apply imports from other agent installs.
- **`agentimport/openclaw`** — OpenClaw migration engine: find directories, preflight, preview, backup, apply, and clean up leftovers.
- **`app`** — The interactive CLI application: chat turns, banner, command handlers, sessions commands, uninstall, relaunch, terminal handling.
- **`backup`** — Home backup and restore: full zips, quick snapshots, SQLite backup, integrity checks, pre-update and pre-migration backups.
- **`batchrun`** — Runs the agent over a JSONL prompt dataset in parallel workers, writing trajectories, checkpoints and statistics.
- **`botdesktop`** — Manages the bot's desktop Chromium: executable choice, profile directory, dock launcher, sandbox, idle watch, thumbnails.
- **`botmode`** — Bot-mode direct-message plumbing: per-user payload cache, orphan cleanup, CLI launcher resolution, probes.
- **`botmode/dmdelivery`** — Runner entry delivering a bot direct message to a live target, with typed refusal and retry errors.
- **`browser`** — Browser tools driving Chromium, Lightpanda, cloud or attached browsers over the Chrome DevTools Protocol.
- **`browser/quiet`** — Launch switches and profile seeds stopping agent-started Chromium from calling Google services on its own.
- **`cliui`** — Classic CLI console toolkit: colors, prompts, select menus, lists, live output, masked secret input.
- **`codeexec`** — Code-execution tool running user code in child processes and kernels, plus the computer-use backends.
- **`commands`** — Defines slash commands and the CLI argument-parser tree, dispatching them to bound handlers.
- **`config`** — Nested config document: dotted paths, deep merge, defaults, atomic writes, backups, diagnostics, profile layers.
- **`config/remote`** — Remote config-plane backend: HTTP client, credentials, paths and diffs against a central configuration service.
- **`config/roundtrip`** — Line-level diffing that ensures config and dotenv rewrites change only the intended keys.
- **`containerinit`** — Linux container image init: verb dispatch, root privilege drop, accounts, environment, bootstrap, supervision.
- **`containerinit/stage`** — Bootstrap step entries that the container init delegates to the service account.
- **`cron`** — Scheduled-job system: job store, scheduler, blueprints, CLI commands, manual triggering, delivery, health.
- **`errchain`** — Names the chain of wrapped Go errors for logs, plus person-readable value and OS error text.
- **`fetch`** — Downloads assets pinned by size and sha256 into a verified cache under the data root.
- **`filedrop`** — Detects dragged or pasted file paths at the start of user input and resolves attachments.
- **`gitcred`** — Resolves GitHub tokens and owned credentials into the basic-auth pair that git sends.
- **`goals`** — `/goal` command: goal state, manager and judge prompts deciding whether another turn follows.
- **`home`** — Resolves the icebath home directory, its named profiles, layout, directory ACLs and files inside.
- **`hostinfo`** — Cached machine facts: OS, architecture, CPU, memory, GPU, battery, container detection, account.
- **`i18n`** — Layered translation catalogs: bundled locales, supported languages per surface, YAML 1.1 loading.
- **`initprompt`** — Builds the `/init` prompt for generating or merging an AGENTS.md in the session directory.
- **`install`** — In-process installer: release archives, checkout, staged install ladder, shell PATH setup, binary update.
- **`installidentity`** — Reads or atomically mints the opaque, process-cached install identity under a root.
- **`kanban`** — Kanban boards in SQLite: tasks, claims, completion, worker dispatch, owner recovery, `icebath kanban` CLI.
- **`linktier`** — Records which build tiers are linked into this binary and words refusals for missing features.
- **`logging`** — Logging setup: handlers, redacting formatters, rotating files, queues, session routing, stderr streams.
- **`lsp`** — Runs language servers over stdio and turns their diagnostics into post-write lint verdicts.
- **`mcp`** — Connects configured MCP servers (stdio, OAuth, connectors) and exposes their tools to the agent.
- **`mcpserve`** — Runs icebath as a stdio MCP server over messaging conversations, optionally with icebath tools.
- **`media`** — Image and video generation, text to speech, transcription, voice mode and wake-word tools.
- **`media/edgetts`** — Client that speaks text through the Microsoft Edge read-aloud service, tracking its clock correction.
- **`media/speech`** — Native Piper speech engine and voice catalog, built on the sherpa-onnx binding.
- **`mediacache`** — Gateway media cache: accepted types, size caps, audio container handling, transcoding, age-based cleanup.
- **`memory`** — Memory system: MEMORY.md and USER.md stores, providers, curator, insights and journey.
- **`monitoring`** — Health snapshots for cron and gateway, event emitter, OTLP export, redaction, monitoring command.
- **`periodic`** — Shared scheduler goroutine running callbacks every interval; the timers of agent and cron.
- **`pet`** — Terminal pet: sprite manifests, local and remote stores, state, rendering, sixel output.
- **`pet/generate`** — Generates pet sprite atlases through image generation: prompts, background removal, frame extraction, normalization.
- **`pm`** — Package manager for runtime dependencies: uv lockfiles, Python environments, tools, launchers, workers, updates.
- **`profiles`** — Named profiles: active profile, caches, metadata, distribution manifests, gateway and cron hooks.
- **`profiles/gatewaycreate`** — Asks the gateway serving this terminal to create a profile; one request, one receipt.
- **`profiles/manage`** — Profile operations: create, delete, clone, describe, channels, gateway service, identity, initialization.
- **`provider`** — Resolves model routes and speaks every supported inference wire protocol; credentials, usage, catalogs.
- **`providerregistry`** — Generic named-provider registry type with key normalization and typed registration errors.
- **`relayhost`** — Parent side of a child process hosting Python's `nemo_relay`; the NeMo Relay binding.
- **`relayhost/relaytest`** — Test fixture provisioning a cached venv and a loopback package index for the relay binding.
- **`selfupdate`** — `icebath update` and doctor: channels, sources, custody, fleet restarts, recovery, install identity.
- **`selfupdate/updaterecord`** — Update run records, locks, and custody of update child processes such as git.
- **`settings`** — The one typed registry of every user setting, its layered resolution and single writer.
- **`settings/internal/docgen`** — Command generating `cli-config.yaml.example` and `SETTINGS.md` from the settings registry.
- **`setupflow`** — Question interface through which a gateway setup flow asks the terminal UI.
- **`skills`** — Skills system: bundled skills, slash commands, hub, guard, blueprints, bundles, skill tools.
- **`skills/bundled/autonomous-ai-agents/icebath-agent/templates/clock-widget`** — Template `main` program: a clock widget for the terminal UI, refreshed every second.
- **`startupfast`** — Fast startup paths: `--version` output, update-check hook, conservative container-mode probe.
- **`state`** — SQLite session database: sessions, messages, full-text search, compression records, locks, shared connection registry.
- **`tarzst`** — Packs file trees into deterministic zstd tars and serves them as read-only file systems.
- **`term`** — xterm-compatible terminal emulator: cell grid, scrollback, alternate screen, driving a program on a pty.
- **`termlab`** — Test lab running icebath in real terminal emulators under Xvfb, driven by input and screenshots.
- **`testfakes`** — Re-exports the `internal/fakellm` scripted provider for test code outside `pkg/`.
- **`testfakes/configplane`** — Fake remote config plane for tests: stored profile layers, versions, locks, scripted refusals.
- **`testfakes/configplane/remoteplane`** — Test fixture wiring the fake plane to the remote config backend with a fresh home.
- **`testguard`** — Blank-imports `internal/homeguard` so test binaries outside `pkg/` get the private home.
- **`tokenizers`** — Runs the Hugging Face `tokenizer.json` pipeline: normalizers, pre-tokenizers, models, decoders.
- **`tokenizers/sentencepiece`** — SentencePiece model loader, normalizer and processor for encoding text into tokens.
- **`tokenizers/tiktoken`** — tiktoken BPE encodings such as `cl100k_base`, with cached rank-file loading.
- **`tools`** — Registers model-callable tools and runs them in a session environment: terminal, files, web, approvals, checkpoints.
- **`tools/anydoc`** — Converts documents to Markdown through the embedded anydoc 0.2.4 WebAssembly build.
- **`trajectorycompressor`** — Compresses JSONL trajectories to a target token budget; a standalone command with tokenizer loading.
- **`vault`** — Vault store for items such as payment and address details, keyed by the OS keychain.
- **`webhooksubs`** — File-locked store of webhook subscriptions per home, with conflict-checked replacement.
- **`workspaces`** — Workspace path helpers: normalize paths, find git worktrees and nearest root markers.

## Gateway

- **`gateway`** — Messaging gateway core: sessions, base adapter, access policy, hosted rooms, relay, API server pieces, control socket.
- **`gateway/messagetools`** — Send-message tool and its senders: Slack DM, Telegram Bot API, Microsoft Graph auth and client.
- **`gatewayapi`** — OpenAI-format HTTP API server adapter: chat, streaming responses, jobs, runs, memory sessions.
- **`gatewaycli`** — `icebath gateway` commands: run, status, enroll, setup, container boot reconcile, s6 multiplexing.
- **`gatewayrun`** — `GatewayRunner` controller managing adapter lifecycles and routing messages between platforms and agents.
- **`gateway/platforms/a2a`** — Inbound Agent2Agent server adapter routing peer tasks into the live gateway session.
- **`gateway/platforms/bluebubbles`** — iMessage adapter through a BlueBubbles server's REST API and webhook callbacks.
- **`gateway/platforms/bundled`** — Blank-imports every bundled platform package so each registers its plugin and adapter.
- **`gateway/platforms/buzz`** — Buzz adapter: NIP-42 websocket subscription in with CLI polling fallback, buzz CLI out.
- **`gateway/platforms/dingtalk`** — DingTalk Stream Mode adapter replying through session webhooks or AI cards.
- **`gateway/platforms/discord`** — Discord bot adapter: guilds, DMs, threads, slash commands, button approvals, reactions, attachments.
- **`gateway/platforms/email`** — Email adapter receiving through polled IMAP and sending through SMTP.
- **`gateway/platforms/feishu`** — Feishu and Lark bot adapter over the Open Platform SDK, including webhooks and comment agents.
- **`gateway/platforms/feishu/feishuclient`** — Carries a comment-agent turn's Lark client through context to the doc and drive tools.
- **`gateway/platforms/googlechat`** — Google Chat adapter: Pub/Sub or HTTP callbacks in, Chat REST API and cards out.
- **`gateway/platforms/homeassistant`** — Home Assistant adapter turning state-change events into messages and replies into persistent notifications.
- **`gateway/platforms/hosted`** — Adapter wrapping a platform object that lives in the plugin host, bridging it to Go.
- **`gateway/platforms/irc`** — IRC adapter over one TCP or TLS stream: addressed messages in, PRIVMSG lines out.
- **`gateway/platforms/line`** — LINE Messaging API adapter: signature-verified webhook in, reply or push out.
- **`gateway/platforms/matrix`** — Matrix adapter for any homeserver, with optional end-to-end encryption, reactions and formatting.
- **`gateway/platforms/mattermost`** — Mattermost adapter over REST v4 and its WebSocket, self-hosted or cloud.
- **`gateway/platforms/ntfy`** — ntfy adapter: streaming JSON subscription in, one POST per reply out.
- **`gateway/platforms/photon`** — Photon adapter supervising a Node sidecar that carries the spectrum-ts gRPC stream both ways.
- **`gateway/platforms/qqbot`** — Official QQ Bot adapter: websocket gateway inbound, REST API outbound, chunked uploads.
- **`gateway/platforms/raft`** — Local HTTP endpoint receiving content-free wake hints from the Raft channel bridge.
- **`gateway/platforms/signal`** — Signal adapter bridging a signal-cli daemon: SSE inbound, JSON-RPC outbound, rate limiting.
- **`gateway/platforms/simplex`** — SimpleX Chat adapter over the simplex-chat daemon's WebSocket API.
- **`gateway/platforms/slack`** — Slack adapter over Socket Mode: workspace clients, slash commands, interactivity, reactions.
- **`gateway/platforms/slack/slacktest`** — Loopback fake Slack for tests, serving the Web API and a Socket Mode websocket.
- **`gateway/platforms/sms`** — Twilio SMS adapter with one session per inbound phone number.
- **`gateway/platforms/teams`** — Microsoft Teams adapter over the Bot Framework REST API with an inbound webhook.
- **`gateway/platforms/telegram`** — Telegram bot adapter: MarkdownV2 replies, forum and DM topics, media, polling watchdog.
- **`gateway/platforms/wecom`** — WeCom adapters: AI Bot over a persistent websocket, and callback mode for self-built apps.
- **`gateway/platforms/weixin`** — Personal WeChat adapter over the iLink bot API, with QR login and long polling.
- **`gateway/platforms/whatsapp`** — WhatsApp adapter over an in-process whatsmeow bridge, with QR pairing.
- **`gateway/platforms/whatsappcloud`** — WhatsApp Business Cloud adapter: Graph API out, signed Meta webhook in.
- **`gateway/platforms/yuanbao`** — Yuanbao bot adapter over a persistent signed websocket, with a middleware inbound pipeline.

## Plugins

- **`builtin`** — Compiled-in plugin support: EGM personas, hallmark and impeccable engines, hooks, embedded payload trees.
- **`builtin/agentimporters`** — Catalog plugin port exposing the import-agent and claw commands plus the openclaw-migration skill.
- **`builtin/camofox`** — Camofox toolset driving a self-hosted camofox-browser server over its REST API.
- **`builtin/delegationdefault`** — Compiled-in default delegation provider routing every task through the delegation config section.
- **`builtin/diskcleanup`** — Compiled-in disk-cleanup plugin tracking paths and running quick cleanups with per-category totals.
- **`builtin/googlemeet`** — Google Meet plugin: meeting bot, page driver, audio bridge, node client and server, process manager.
- **`builtin/langfuse`** — Traces turns, model calls, tool calls and subagents to Langfuse over its OpenTelemetry endpoint.
- **`builtin/mcpserveplugin`** — Catalog plugin port that provides the `icebath mcp-serve` command.
- **`builtin/securityguidance`** — Compiled-in security-guidance plugin: rules that fire on file paths and content patterns.
- **`builtin/spotify`** — Spotify catalog plugin port: seven Web API tools and the `icebath spotify` login command.
- **`builtin/teamspipeline`** — Teams meeting pipeline plugin: Graph subscriptions, meeting notifications, durable JSON state store, CLI.
- **`builtin/webbackends`** — Compiles the bundled web search and extract backends in as `plugins/web/<vendor>` plugins.
- **`plugins`** — Discovers, loads, installs, activates and dispatches plugins through one registration context; catalog and capabilities.
- **`plugins/defaults`** — Installs the catalog plugins marked default into every home once, through a detached child.
- **`plugins/verify`** — Plugin verification runner: recipe phases, readiness polling, evidence, hooks, child termination.
- **`pluginsdk`** — SDK that plugins build against: CLI commands, cron schedulers, events, hosts, platform adapters, provider profiles.
- **`pluginservices`** — Aggregates every provider registry that plugins register into, for the main binary.
- **`plugintree`** — Embeds the bundled plugin files and catalog plugin trees that plugin readers consult.

## Terminal UI

- **`tui`** — The Bubble Tea terminal UI application: transcript, composer, hub, slash commands, widgets.
- **`tuigateway`** — Typed wire contract between TUI and gateway: methods, requests, events, parameter and result types.
- **`tuihost`** — Hosts TUI sessions: stdio and WebSocket transports, live session registry, event replay, tool progress.
- **`tuiserver`** — RPC server behind the TUI: session, prompt, tools, voice and hub methods; change watchers.
- **`ui/anim`** — Spring-driven animated scalars and rectangles used for motion in the terminal UI.
- **`ui/cards`** — Window-manager cards (composer, forms, lists, reader, terminal, hub) sharing theme, keys and settings.
- **`ui/clip`** — Writes text to the user's clipboard and asks the terminal for its clipboard contents.
- **`ui/field`** — The line editor every text field of the toolkit types into, driven by keymap actions.
- **`ui/gfx`** — Draws pixel images over terminal cells through whichever graphics protocol the terminal verifiably supports.
- **`ui/keys`** — Per-context keybindings that every legend, palette and menu derive from, kept in one file.
- **`ui/lang`** — Gives the UI kit the text of a string key in the application's language.
- **`ui/render`** — Shared text rendering for cards: markdown, code, diffs, tables and small theme-tuned formatters.
- **`ui/render/recap`** — Builds a plain multi-line recap of recent session activity from in-memory history.
- **`ui/theme`** — Colors, chrome and art shared by every icebath surface.
- **`ui/tty`** — Terminal output stage turning Bubble Tea views into the fewest bytes a terminal needs.
- **`ui/txt`** — Generated typed keys for the terminal UI text catalog, one per English entry.
- **`ui/txt/internal/keygen`** — Command generating `pkg/ui/txt/keys.go` from the English TUI locale catalog.
- **`ui/wm`** — Tiling window manager for terminal cards: workspaces, floating dialogs, command palette, spring motion.
- **`vxl`** — Voxel renderer for terminals: lit rasterizer, voxel grids, posable figures, cell encoders.
- **`vxl/arena`** — Arena card showing the agent crew as a voxel scene, with input, replay and journal.
- **`vxl/internal/glyphgen`** — Command generating `pkg/vxl/glyphs.go` by rasterizing glyphs from their Unicode-name geometry.

## Internal

- **`internal/fakellm`** — Scripted fake `/chat/completions` server for tests, streaming canned text, reasoning and tool-call turns.
- **`internal/fnmatch`** — Port of Python's `fnmatch`: shell-pattern matching through cached compiled regexes, with `normcase` handling.
- **`internal/hermetic`** — Test isolation helpers: blocks non-loopback HTTP, restores environment and working directory, unpacks fixture archives.
- **`internal/homeguard`** — Gives each test binary a private home and scratch directory, removed afterwards; imported for side effect.
- **`internal/msalruntime`** — Binding to Microsoft's native MSAL runtime library (v0.20.7) for brokered authentication.
- **`internal/netpref`** — Process-wide IPv4 preference that outbound dialers and HTTP transports follow at each dial.
- **`internal/proc`** — Cross-platform, psutil-style process inspection: snapshots, parents, identity, executable, working directory, memory, open files.
- **`internal/pvporcupine`** — Binding to Picovoice's native Porcupine wake-word engine, with its status codes and message stacks.
- **`internal/ruamelyaml`** — Port of the ruamel.yaml 0.18.16 load stack and libyaml parser: reader, scanner, parser, composer, resolver.
- **`internal/sherpaonnx`** — Binding to the sherpa-onnx C API (v1.13.8) for keyword spotting and speech.
- **`internal/treekill`** — Kills whole process trees, recording pid plus start time so a reused pid is never signalled.

## Utils

- **`utils/acp`** — Agent Client Protocol library: connections, framing, initialize, content and methods for the agent side.
- **`utils/any`** — Dynamic-value helpers: deep clone, deep equality, kind names, number and string conversion, truthiness.
- **`utils/base64`** — Lenient base64 decoding: standard or URL-safe alphabets, optional padding, whitespace ignored.
- **`utils/browser`** — Opens a URL in the user's browser through `BROWSER` entries or platform openers.
- **`utils/charset`** — Character-set decoding and encoding: single-byte, multibyte, ISO-2022, UTF-7, UTF variants, locale names.
- **`utils/console`** — Rich-style console rendering: markup, colors, panels, tables, progress, live output, markdown, emoji, highlighting.
- **`utils/cpython`** — Binding to libpython's C API: GIL, calls, attributes, classes, conversion, exceptions, async.
- **`utils/ctx`** — Context helpers: a non-blocking dispatch mark and a mutable per-context variable store.
- **`utils/diff`** — Sequence similarity ratio and closest-match lookup, in the manner of Python's difflib.
- **`utils/dl`** — Dynamic library loading: find and open shared libraries, C strings, callbacks into Go.
- **`utils/error`** — Errors carrying a kind label, plus classification such as whether an error is system-originated.
- **`utils/exec`** — Runs commands with timeouts, captured output, exit-status errors, shell selection, process-group kill.
- **`utils/fernet`** — Fernet symmetric token encryption and decryption over one key, with key generation.
- **`utils/fs`** — Filesystem helpers: metadata-preserving copy, copytree, file locks, disk usage, access times, file identity.
- **`utils/host`** — Platform naming like Python's `platform` module: OS name, machine, release, libc, platform label.
- **`utils/http`** — HTTP client helpers: shared transport, proxies, redirects, content decoding, JSON bodies, Retry-After, TLS, timeouts.
- **`utils/image`** — Image conversion to straight-alpha RGBA, palette quantization, alpha-aware resampling, resizing and thumbnails.
- **`utils/json`** — JSON decode and encode with ordered objects, big integers, partial parsing, strict options, validation.
- **`utils/jsonschema`** — JSON Schema compiler and validator across drafts, with formats and best-match errors.
- **`utils/jwt`** — Cached JWK set client and parsing of its RSA and ECDSA public keys.
- **`utils/mail`** — Mail library: address parsing, MIME message building and parsing, IMAP and SMTP clients.
- **`utils/math`** — Numeric helpers: linspace, half-even rounding, moving-average smoothing, RMS and statistics.
- **`utils/mime`** — Media type and file extension lookup tables, by name, extension or URL.
- **`utils/net`** — IP address parsing and classification into private, reserved and shared (carrier-grade NAT) ranges.
- **`utils/ordered`** — Generic map remembering key insertion order, with ordered iteration and merge operations.
- **`utils/path`** — Path helpers: dot-dot-preserving clean, home and env expansion, file URLs, globbing, case folding, resolve.
- **`utils/plist`** — Property list encoding and decoding in XML, binary and text formats.
- **`utils/portaudio`** — Binding to the PortAudio library: devices, host APIs, streams and buffer playback.
- **`utils/python`** — Python source parser and compile checker reproducing CPython's syntax errors; literals, repr, launcher.
- **`utils/qr`** — QR code encoder: segmentation, masking, error-correction levels and rendering.
- **`utils/regex`** — Regex compilation with dialect translation, options such as ignore-case and whole-match, lazy patterns.
- **`utils/shell`** — POSIX shell quoting, joining and word splitting, in the manner of Python's shlex.
- **`utils/sqlite`** — SQLite extras: authorizers, online backup, custom functions, hooks, progress, tracing, transactions.
- **`utils/sync`** — Concurrency primitives: bounded runs, events, goroutine IDs and locals, polling, reentrant locks, semaphores.
- **`utils/tar`** — Tar creation as `.tar.gz` and safe extraction with link and permission checks.
- **`utils/template`** — `{name}` and `{name:spec}` format-string templates, parsed once and rendered concurrently.
- **`utils/term`** — Terminal size detection, stdout and stderr routing, and stream capability unwrapping.
- **`utils/text`** — Text helpers: case folding, titling, character classes, newlines, padding, parsing, UTF-8, wrapping.
- **`utils/time`** — Dates, epochs, ISO parsing, strftime, monotonic clocks, tzdata and YAML timestamps.
- **`utils/toml`** — TOML decoding into plain or order-preserving documents, and encoding back to text.
- **`utils/unicode`** — Unicode general categories and code-point lookup by character name or alias.
- **`utils/url`** — URL helpers: base host, origin and path, escaping, file URLs, ports, query strings, splitting.
- **`utils/user`** — User and group database lookups, login name and home directories.
- **`utils/version`** — Parses and compares package versions: epochs, pre, post and dev releases, local labels.
- **`utils/wakeword`** — openWakeWord engine on TensorFlow Lite: bundle loading, feature front end, model stages.
- **`utils/websocket`** — WebSocket client connection: dialing, keepalive pings, close handling, concurrency-safe writes.
- **`utils/zip`** — Zip reading and safe extraction with size limits, Deflate64 and LZMA, legacy name decoding.
